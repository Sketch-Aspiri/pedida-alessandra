# Pedida Alessandra

Página especial de Andres para Alessandra.

## Abrir en local

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

Luego abre http://127.0.0.1:5173

## Deploy Vercel

```bash
npx vercel --prod
```

Archivos: `index.html`, `styles.css`, `app.js`, `vercel.json`, `package.json`
